# New-Year-Countdown-
This project is a simple and attractive New Year Countdown Web App created using HTML, CSS, and JavaScript.
It displays the remaining:

* Days
* Hours
* Minutes
* Seconds

until New Year 2027.

When the countdown ends, it shows a Happy New Year message.


Features

* Real-time countdown timer
* Responsive design
* Modern glassmorphism UI
* Automatic update every second
* Celebration message after countdown ends


Technologies Used

* HTML5
* CSS3
* JavaScript

  Project Structure
│
├── index.html


How It Works

HTML

Creates the structure for:

* Heading
* Countdown boxes
* Celebration message

CSS

Used for:

* Background gradient
* Glass effect container
* Responsive layout
* Styling timer boxes

JavaScript

Performs:

* Date calculation
* Time conversion
* Live countdown updates
* Displaying New Year message

  Countdown Formula
  const distance = newYear - now;

  Time Conversion
  Days = distance / (1000 * 60 * 60 * 24)
Hours = ...
Minutes = ...
Seconds = ...

Output:
New Year Countdown 2027

120 Days | 10 Hours | 25 Minutes | 30 Seconds
