# New-Year-Countdown-
This project is a simple and attractive New Year Countdown Web App created using HTML, CSS, and JavaScript.
It displays the remaining:

* Days
* Hours
* Minutes
* Seconds

until New Year 2027.

When the countdown ends, it shows a Happy New Year message.


Features

* Real-time countdown timer
* Responsive design
* Modern glassmorphism UI
* Automatic update every second
* Celebration message after countdown ends


Technologies Used

* HTML5
* CSS3
* JavaScript
